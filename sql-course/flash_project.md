# Flash Project: Employee Insights & Department Performance

This is a short capstone project for the SQL course. It combines the most important ideas from the notebook: joins, group-by logic, CASE expressions, CTEs, and window functions.

## Goal
Use SQL to answer business questions such as:
- Which departments have the highest average salary?
- Who are the top performers by department?
- Which employees fall into each salary tier?
- What is a simple executive summary by department?

## Suggested workflow
1. Create the employee, department, and performance datasets.
2. Join the tables to build an organization overview.
3. Calculate average salaries by department.
4. Rank employees by performance score within each department.
5. Categorize employees into salary tiers with CASE WHEN.
6. Build a final summary report for leadership.

## Key SQL concepts used
- JOIN / LEFT JOIN
- GROUP BY and aggregate functions
- CASE WHEN
- WITH / CTE
- WINDOW functions such as RANK() OVER
- ORDER BY and sorting

## Why this is a good flash project
- It is realistic and easy to understand.
- It connects directly to the examples in the course.
- It shows how SQL is used for decision-making in business settings.
- It can be extended later with sales, product, or finance data.
